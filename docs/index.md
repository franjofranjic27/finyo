# finyo

finyo is a personal finance planner for Swiss residents: accounts, transactions,
budgets, investments and Swiss-specific tooling such as a pillar 3a tax
calculator. A Spring Boot REST API and a React SPA, self-hosted behind Keycloak.

- **Live:** [finyo.frama-maschinenhandel.ch](https://finyo.frama-maschinenhandel.ch)
- **Source:** [github.com/franjofranjic27/finyo](https://github.com/franjofranjic27/finyo)
